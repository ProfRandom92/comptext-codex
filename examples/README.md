# CompText Examples

This directory contains 55+ executable examples demonstrating CompText-Codex capabilities.

## Directory Structure

- **basic/** - Core commands and basic operations
- **ml_pipelines/** - Machine learning workflows
- **documentation/** - Documentation generation
- **security/** - Security and compliance checks
- **frontend/** - UI component generation

## Running Examples

```bash
# Install CompText first
pip install -e .

# Run any example
python examples/basic/text_compression.py
python examples/ml_pipelines/automl_classification.py
```

## Categories

1. **Basic Operations** - Text compression, analysis, formatting
2. **ML Pipelines** - AutoML, feature engineering, model evaluation
3. **Documentation** - API docs, changelogs, tutorials
4. **Security** - Vulnerability scans, GDPR compliance
5. **Frontend** - React components, dashboards

## Contributing

Add new examples following the existing structure. Each example should:
- Be self-contained and runnable
- Include docstrings explaining the use case
- Demonstrate token savings vs natural language
